## Langkah-Langkah Pengerjaan

### 1. Membuat Folder Project

Membuat folder dengan nama `Praktikum 2` sebagai tempat menyimpan seluruh file praktikum.

### 2. Membuat File HTML

Membuat file `index.html` dan `biodata.html` menggunakan Visual Studio Code.

### 3. Membuat Tabel

Membuat tabel menggunakan elemen `<table>`, `<tr>`, `<th>`, dan `<td>` untuk menampilkan data mahasiswa.

### 4. Membuat Form

Membuat form biodata menggunakan `<form>` dengan beberapa jenis input seperti text, email, radio button, checkbox, select, dan textarea.

### 5. Menambahkan Validasi

Menambahkan atribut `required` dan validasi dasar lainnya agar data yang dimasukkan sesuai dengan ketentuan.

### 6. Menggunakan Semantic HTML

Menggunakan elemen semantic seperti `<header>`, `<nav>`, `<main>`, `<section>`, dan `<footer>` untuk membuat struktur halaman lebih jelas.

### 7. Menambahkan Audio dan Video

Membuat folder `media`, kemudian memasukkan file audio `.mp3` dan video `.mp4`. File tersebut ditampilkan pada halaman HTML menggunakan elemen `<audio>` dan `<video>`.

### 8. Membuat Mini Project Biodata

Menggabungkan materi tabel, form, semantic HTML, audio, dan video ke dalam halaman `biodata.html`.

### 9. Melakukan Pengujian

Membuka file HTML melalui browser untuk memastikan tabel, form, validasi, audio, dan video dapat berfungsi dengan baik.

## Kesimpulan

Praktikum ini memberikan pemahaman mengenai dasar-dasar HTML, mulai dari pembuatan tabel dan form hingga penggunaan semantic HTML serta media audio dan video.
